Xray Config UI Editor — Web GUI for Xray-core

A powerful static web-based interface to create, edit, visualize, and manage Xray-core configurations in your browser.

Key Features:

  • Full Config Management: Inbounds, Outbounds, Routing, DNS, Policy, Reverse, and Stats.
  • Direct Remnawave Panel sync via API.
  • Interactive visual traffic flow topology (powered by React Flow).
  • Built-in VLESS Reality keypair generator (X25519).
  • Drag & drop routing rule manager.
  • Dual-mode editing: user-friendly GUI and raw JSON editor with syntax validation.
